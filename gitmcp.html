Wiring up the GitHub MCP server

Model Context Protocol (MCP) lets an AI coding tool call GitHub's API directly — opening PRs, reading issues, checking CI — instead of you copy-pasting things into chat. GitHub hosts an official remote server, so no local install is required. Same idea, three different config files.

Claude Code CLI command

Configured with the claude mcp command, not by hand-editing a file.

# get a fine-grained PAT first: github.com/settings/personal-access-tokens
claude mcp add --transport http github https://api.githubcopilot.com/mcp/ \
  --header "Authorization: Bearer YOUR_GITHUB_PAT"

Or, if you want it checked into the repo for teammates (project scope), it writes to .mcp.json:

{
  "mcpServers": {
    "github": {
      "type": "http",
      "url": "https://api.githubcopilot.com/mcp",
      "headers": { "Authorization": "Bearer ${GITHUB_PERSONAL_ACCESS_TOKEN}" }
    }
  }
}

Verify with /mcp inside a Claude Code session — it should show connected.

OpenCode opencode.json

Lives in opencode.json, edited directly.

{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "github": {
      "type": "remote",
      "url": "https://api.githubcopilot.com/mcp",
      "enabled": true,
      "headers": {
        "Authorization": "Bearer ${GITHUB_PERSONAL_ACCESS_TOKEN}"
      }
    }
  }
}

Prefer a locally-run server instead of GitHub's hosted one? Use "type": "local" with a command array (e.g. npx -y @modelcontextprotocol/server-github) and an environment block for the token.

Codex CLI config.toml

TOML, not JSON, in ~/.codex/config.toml (global) or .codex/config.toml (per project).

[mcp_servers.github]
url = "https://api.githubcopilot.com/mcp/"
bearer_token_env_var = "GITHUB_PAT_TOKEN"

Then export the token before launching Codex, or put it in a .env file:

export GITHUB_PAT_TOKEN=ghp_your_token_here

Or skip the file entirely and let the CLI write it for you:

codex mcp add github --url https://api.githubcopilot.com/mcp/ \
  --bearer-token-env-var GITHUB_PAT_TOKEN

The 3-step mental model

  1. Get a token. Generate a fine-grained GitHub PAT scoped only to the repos you need.
  2. Point your tool at the server. Same URL everywhere: https://api.githubcopilot.com/mcp/ — just different syntax per tool.
  3. Check the connection. claude mcp list, OpenCode's server status, or codex mcp list — always verify before assuming it works.
Never commit a real token into a config file — use an env var reference instead.
