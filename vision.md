# Project Vision

## Project Name

AI Task Manager Demo

---

## Objective

Build a simple production-style Flask application to demonstrate an AI-assisted software delivery workflow.

The project should demonstrate how AI agents can help with:

- Planning
- Coding
- Testing
- Security scanning
- Code review
- Issue management
- Fix automation
- Documentation
- Docker deployment

---

## Application Features

The application should provide:

- User authentication
- Login/logout
- User dashboard
- Task management APIs
- Health check API

---

## Technology Stack

- Python 3.11+
- Flask
- SQLite
- SQLAlchemy
- Pytest
- Docker
- GitHub Actions

---
